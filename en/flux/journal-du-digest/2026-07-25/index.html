An exploration of tags and a look back at 2017

Two old hand-compiled Digests, from weeks 8 and 9 of 2017, have been added to the archive. The tag browser now features an alphabetical index and the links now have favicons, whilst cache issues have been resolved.

Requests and discussions

This section has been reconstructed from the commits and their diffs.

The work demonstrates a deliberate alternation between content and interface: re-importing an HTML version, observing how it is viewed, then improving the navigation before continuing with the import. The successive fixes relating to the cache indicate that the actual deployment served as a test, and that a simple modification to the source file did not guarantee that the browser would load the new version.

Decisions

  • The 2017 restoration is carried out edition by edition, with its tags and import source preserved.
  • Tags must be browsable alphabetically, not just filtered via search.
  • Custom front-end resources use an explicit versioning strategy to bypass caches.
  • Favicons enhance visual identification without replacing the title or the editorial description.

Implementation

Week 8 of 2017 is added with its categories and tags. Three iterations then improve the explorer: formatting, alphabetical index, then script versioning.

Week 9 expands the catalogue with new topics and introduces favicons to the homepage, archives, feed and tag pages. Two final fixes stabilise the cache busting.
