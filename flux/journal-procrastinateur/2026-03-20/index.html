Les photos entrent vraiment dans Krampouz

Journée charnière. 14 commits, quasi tous des features. C’est le jour ou les photos entrent réellement dans Krampouz.

Ça commence par la fondation du pipeline R2 : 24 fichiers, 1323 lignes. Upload direct vers Cloudflare R2 avec URLs presignees, gestion des assets, lien entre projets et fichiers uploades. Puis le durcissement du mode R2 réel (vs MinIO local).

Ensuite la galerie photo se construit a vitesse grand V : feedback pipeline améliore, actions bulk admin sur les photos, console admin projets/PDF, déduplication SHA256, contrôles galerie, interactions raffinement dans l’éditeur. Les 8 derniers commits sont un enchaînement rapide de features et polish sur le panneau photos.

Le dernier commit de la journée traite un sujet délicat : permettre la suppression de photos déjà utilisées dans des projets.

R2, galerie, empreintes et administration

  • Pipeline R2 complet (upload présigné, stockage, retrieval)
  • Galerie photos dans l’éditeur
  • Déduplication SHA256 des photos
  • Actions bulk admin (suppression, reprocessing)
  • Console admin projets et PDF
  • Insertion photo dans le canvas avec taille cohérente
  • Suppression de photos utilisées

Ne pas dédupliquer entre les clients

La déduplication SHA256 évite de traiter deux fois la même image. Décision importante : pas de déduplication cross-tenant. Chaque tenant a ses propres assets.

La suppression de photos utilisées est un sujet piège : on decide que oui, avec un système de réconciliation qui nettoie les références cassées.

Quatorze commits pour une seule chaîne média

14 commits de features en une journée, c’est le pic de productivité du projet. L’assistance IA permet de construire des fonctionnalités complètes (backend + frontend + admin) dans un temps qui serait impossible en solo. Le risque c’est la dette technique invisible.

R2 plutôt que S3 direct est un choix pragmatique : même API, moins cher, pas de vendor lock-in AWS.

Le lot assets devient tangible

Le Lot A (photos client) avance massivement. La galerie est fonctionnelle, l’upload marche, l’insertion dans le canvas aussi.

La chaîne R2 de bout en bout

  • Pipeline R2 : routes upload, URLs presignees
  • Galerie photos et déduplication SHA256
  • Console admin projets/PDF (18 fichiers, 1530 lignes)

Donner un vrai gestionnaire aux photos

Le photo manager se raffine : métadonnées, localisation, UX d’enrichissement.

Repères : R2, URL signée et SHA

  • Cloudflare R2 — stockage objet compatible S3, utilise ici pour les fichiers image.
  • URL presignee — lien temporaire autorisant un upload ou un accès direct à un fichier.
  • SHA256 — empreinte numérique d’un fichier, utile pour détecter les doublons.
  • tenant — espace logique d’un client ou d’une organisation dans une architecture multi-tenant.
