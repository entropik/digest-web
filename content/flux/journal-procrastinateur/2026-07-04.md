## Lecture courte

Petite journée en commits, mais utile pour la reprise de contexte.

Le commit `6abdbb03` ajoute le wiki KEREDIT sous `docs/KEREDIT/` : point
d'entrée Codex, schéma, concepts, entites, requêtes de navigation et réglages
Obsidian. L'objectif n'est pas de remplacer la documentation source. C'est une
carte compacte pour qu'un agent sache ou commencer avant de toucher au code.

Le même commit aligne `AGENTS.md`, `docs/HOME.md`, `docs/index.md`,
`docs/log.md` et `docs/okf.md` pour rendre cette couche visible sans lui donner
plus d'autorité que le code ou les docs normatives.

Le commit `33d9cb35` corrige ensuite un lien relatif dans le guide Prisma. C'est
le genre de détail qui compte dans une documentation OKF : si les chemins
cassent, la carte cesse vite d'être fiable.

## Pour la suite

La règle a retenir est simple : pour un chantier non trivial, lire
`docs/KEREDIT/START_HERE_CODEX.md`, puis seulement les 1 a 3 pages concept
nécessaires, et revenir au code courant avant toute modification.
