Jour 108 - La pagination devient un contrat print

Jour 108 du journal : pagination durcie dans KEREDIT, rendue avec les polices GOF et protégée jusqu'au deploy et a Accurio.

Horaires de session

  • Agent utilisé : Codex
  • Environnement principal : VS Code WSL, plugin Codex, repos KEREDIT et GOF
  • Date couverte : jeudi 9 juillet 2026
  • Branches observées : dev dans KEREDIT et GOF
  • SHA KEREDIT de fin de séquence : 9a99378 (ui: compact admin projects list)
  • SHA GOF de fin de séquence : 7b40578 (chore: run preflight before forge deploy)
  • Versions observées : KEREDIT 0.10.17, GOF 0.2.9
  • Commits directs observés : 6 KEREDIT + 5 GOF
  • Temps minimal observe le 9 juillet : 4h29+ d’amplitude multi-dépôts (17:40 -> 22:09, hors tests et vérification manuelle)
  • Temps cumulé :685h49+ (681h20+ au 8 juillet, + 4h29+)

Lecture courte

Hier, la pagination entrait dans l’éditeur. Aujourd’hui, elle doit arrêter de se comporter comme un simple bloc graphique et devenir une donnée stable jusqu’au PDF de production.

La journée est plus courte en amplitude, mais très cohérente entre les deux dépôts : KEREDIT durcit le contrat, GOF apprend a le rendre avec les bonnes polices.

KEREDIT protege le sens de la pagination

99e6898 traverse les surfaces de l’éditeur pour stabiliser les contrôles de pagination. Le champ doit rester identifiable dans le canvas, les panneaux, le texte et l’état partage.

f3ba7b5 ajoute ensuite la couverture du contrat JSON cote payload et renderer. La documentation du projet JSON est alignée avec les tests, ce qui transforme le comportement en contrat vérifiable.

d8acb97 exclut enfin la pagination du snapping. Un numéro de page dynamique ne doit pas se comporter comme un bloc ordinaire que les guides magnétiques deplacent ou requalifient par accident.

La séquence passe par 0.10.16, puis les fichiers de package atteignent 0.10.17. L’admin projets est aussi compacté en fin de journée.

GOF rend avec les polices du manifeste

d24c655 relie le rendu de pagination au moteur glyph-level et aux polices du manifeste GOF. Le numéro de page doit rester du texte PDF natif, avec la même famille que celle choisie dans KEREDIT.

8643c38 aligne ensuite le répertoire runtime des polices entre environnement, compose et documentation. Une police disponible par hasard sur une machine ne doit jamais devenir une dépendance de production.

Accurio et le deploy gagnent des garde-fous

26e8b15 permet de relancer seulement une pièce Accurio, utile quand couverture et cahier n’ont pas le même destin. Le retry n’a plus besoin de reproduire toute la commande.

Deux petites corrections ferment le lot : message de forçage echappe dans le dashboard, puis preflight obligatoire avant déployer la forge.

Pour la suite

Le prochain verrou est la parité des styles et de la géométrie entre KEREDIT et GOF. Une pagination correcte ne suffit pas si une variante de police ou un clipart change encore entre l’écran et le PDF.
