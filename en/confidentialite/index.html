Privacy Policy

Privacy Policy for the OOBLIK Digest — Curation browser extension.
2 September 2026 · Marc

These rules describe the data processed by the OOBLIK Digest — Curation Chrome and Firefox extension, how it is used, and the choices available to the user.

The sole purpose of the extension is to manually save the active page to OOBLIK Digest’s private editorial queue in preparation for a future issue. It is intended for the owner of the Digest.

Data processed#

The extension only reads a page following an explicit action on its icon or via its keyboard shortcut. It may then pre-populate the form with:

  • the address of the active page and its canonical address, if any;
  • its title and meta description;
  • any text selected by the user;
  • the category, summary and tags entered or corrected in the form;
  • a private editorial note entered by the user.

This data relates primarily to browsing history and the content of the website, as defined in the Chrome Web Store and Firefox Add-ons policies. The extension does not monitor browsing, does not maintain any general history and does not collect any data in the background.

Time of transmission and purpose#

All information is displayed in the form before it is submitted. It is only transmitted when the ‘Save draft’ button is clicked, via HTTPS, to digest.ooblik.com.

It is used exclusively to:

  • pre-filling and saving a private editorial draft;
  • detect duplicates;
  • prepare, proofread and voluntarily publish an edition of the Digest;
  • ensuring the technical and editorial traceability of publications.

The extension does not use the data for advertising, profiling, commercial audience measurement, credit checks or any other purpose.

Private data and publication#

The selected text and editorial note remain private. They are never added to the public catalogue, the public archives or Git commits.

The URL, title, summary, category and tags only become public after publication has been explicitly confirmed via the admin panel. This publication is a separate action from saving the draft.

Storage and deletion#

Drafts are stored in the administration service’s private database. An active draft can be edited or deleted via the administration panel.

After publication, its private revision history may be retained to ensure traceability, idempotent recovery and deduplication. Private notes remain private during this retention period. Metadata that has been deliberately published follows the Digest’s editorial retention policy.

Authentication, access and sharing#

The service requires the authorised owner’s GitHub session. No GitHub tokens or administration secrets are read or stored by the extension.

Data is neither sold, nor used for advertising, nor passed on to third parties for their own use. GitHub receives only the metadata that the owner explicitly chooses to publish, for the purposes of versioning and deploying the Digest.

Security#

Communications between the extension and digest.ooblik.com use HTTPS. The administration service requires owner authentication, restricts authorised origins and stores its data on a private server.

The extension does not use any remote code: all JavaScript executed is included in the packages distributed via the Chrome Web Store and Firefox Add-ons.

Browser permissions#

  • activeTab allows the URL and title of the active tab to be read only following a user action;
  • scripting allows the canonical URL, meta description and selected text to be extracted on an ad hoc basis;
  • access to https://digest.ooblik.com/* allows the session to be verified and the draft to be saved in the private admin panel.

The extension does not request access to all websites, nor does it request access to the cookies API.

Firefox also displays, prior to installation, the categories of data required: browsingActivity and websiteContent. These correspond solely to the URL and content that the user chooses to save manually.

Limited use#

The use of information received by the extension complies with the Chrome Web Store and Firefox Add-ons regulations regarding user data, including Chrome’s ‘Limited Use’ requirements. The data is used solely to provide the curation feature described on this page.

Changes and contact#

Any substantial changes to these practices will be published on this page and notified within the extension where required.

If you have any questions, please use the contact details provided on the About page.
