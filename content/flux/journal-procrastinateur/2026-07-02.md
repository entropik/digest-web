## Lecture courte

Petite journée, mais utile.

Le fil du soir est le déploiement VPS : ne plus se contenter d'une version qui
semble bonne si le SHA raconte autre chose. Le script manuel refuse maintenant
plus clairement les cas dangereux : version locale inferieure au VPS, ou même
version avec deux commits différents.

Les commits du jour sont resserres :

- `77c3e79` - bump release **0.9.51** après le chantier remplissage carnet ;
- `43131f3` - durcir le garde-fou de version du deploy VPS ;
- `c948df5` - bump release **0.9.52** pour rendre ce garde-fou deployable.

Ce n'est pas une grande évolution produit. C'est une hygiène de livraison :
KEREDIT doit savoir exactement quel couple **version + SHA** est attendu avant
de toucher le VPS.

## Pour la suite

Le prochain deploy nominal devra rester sur le chemin simple :

```text
validation locale -> push dev -> ./deploy/manual-vps-local.sh -> verification SHA servi
```

Le point de vigilance est toujours le même : ne pas laisser le local, `origin/dev`
et le VPS raconter trois états différents du produit.
