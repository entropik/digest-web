## Lecture courte

La journée s'ouvre sur une nouvelle venue du monde de l'IA. Moonshot AI a
sorti Kimi K3 le 16 juillet : un modèle ouvert de 2,8 billions de paramètres
en mixture d'experts, une fenêtre de contexte d'un million de tokens, des
poids complets annoncés pour le 27 juillet. À 09:54, Kimi Code CLI est
installé sur le Mac avec K3 comme modèle par défaut. Claude Code à lancé le
projet, Codex le porte depuis avril ; un troisième outillage entre en
observation.

L'après-midi et la soirée reviennent à l'atelier avec un fil conducteur :
fermer les portes restées entrebâillées. Cinq pull requests durcissent
l'argent, la configuration, les sessions et les e-mails, sans toucher au cœur
de l'éditeur.

## Le PDF web ne se donne plus, il s'achète

La PR #321 est le morceau central. Le PDF web payant ne peut plus être activé
par le client via les options du projet : l'entitlement est conditionné à une
commande WooCommerce réellement payée.

Le durcissement est méthodique. Un statut de commande inconnu n'est plus
traité comme payé. Les clés d'entitlement sont gelées dès qu'une commande est
liée, et la décision de gel se prend sous le verrou d'écriture. Les droits
déjà accordés par les chemins autorisés sont préservés, y compris sur
rafraîchissement, rotation et rendu GOF, et les commandes legacy sans statut
restent acceptées pour ne pas casser l'existant.

## La configuration GOF appartient à l'admin

La PR #322 réserve la configuration GOF au rôle `admin`. Les URLs sont
validées, la politique d'URL s'applique aussi au pairing, et l'interrupteur
Auto GOF est masqué pour le rôle `editor`. L'éditeur d'un atelier n'a plus
accès aux réglages qui décident de la production.

## Les détails qui comptent

Trois correctifs plus courts complètent la journée. La PR #324 préserve les
couleurs des cliparts partagés, qui se perdaient à la lecture publique. La
PR #325 sécurise les logs de reset et câble les variables du webhook e-mail,
avec les secrets de production fixés dans le test. La PR #327 révoque la
session Better Auth au logout, borne le catch-all `auth-v2`, limite la
révocation à la session courante et expire proprement le cookie préfixé
`__Secure-` en production.

## Un jour de serrage de boulons

Rien de spectaculaire à l'écran, mais c'est le genre de journée qui rend la
bêta défendable : l'argent suit la commande, la configuration suit le rôle,
la session suit le logout. Et dans la matinée, presque en passant, l'atelier
a changé de paysage : un nouveau modèle frontier open-weight est arrivé, et
son CLI est déjà sur la machine.
