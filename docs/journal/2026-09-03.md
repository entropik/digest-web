# 3 septembre 2026 — Le cron choisit sa version de Node

## Résumé

Un écart de version entre le site public et l’administration a révélé deux
circuits de déploiement indépendants et une commande planifiée utilisant une
version de Node trop ancienne. La sélection explicite de Node 22 dans cette
commande est corrigée et documentée, sans redémarrer le service.

## Demandes et échanges

- Expliquer pourquoi le site public et l’administration affichaient des
  versions différentes après une fusion réussie.
- Corriger la commande planifiée concernée, puis conserver la procédure dans
  le dépôt.

## Décisions

- Limiter la correction à l’environnement de la commande admin, sans modifier
  la planification du site public.
- Conserver la tâche système préexistante et signaler son doublon plutôt que
  supprimer implicitement une autre configuration.
- Distinguer la réussite des contrôles GitHub de la version effectivement
  servie par chacun des deux composants.

## Réalisation

- Le diagnostic a retrouvé des échecs d’installation des dépendances natives
  sous Node 20, incompatible avec la version minimale du service.
- Une exécution réussie avait déjà remis les deux interfaces à la même version
  avant la correction du cron.
- La ligne concernée sélectionne explicitement Node 22. Sa configuration
  précédente a été sauvegardée avant remplacement.
- Le README et la procédure d’exploitation décrivent le chemin de Node,
  l’inventaire des planifications et les contrôles après intervention.

## Validation et déploiement

- Node 22.23.1 et npm 10.9.8 ont été vérifiés dans un environnement minimal.
- Le passage suivant du cron corrigé a été confirmé dans les journaux.
- Le contrôle de santé est resté valide et le processus n’a pas été redémarré.
- La correction du cron a été appliquée directement sur le serveur. Ce billet
  et la procédure associée en constituent la trace documentaire dans Git.

## Suite

- Consolider les deux planifications admin lors d’une intervention dédiée,
  en conservant les protections et le contrôle de santé existants.
