Petite journée, mais vrai changement de nature : après les cartes, carnets et lots photo, on a commencé le parcours du tirage d'art grand format. Ce n'est plus un lot rapide. C'est un dossier de tirage, avec un fichier souvent lourd, un format libre, un papier choisi, une attente de rendu, et surtout le regard du tireur.
Le produit cree aujourd'hui porte le code technique `fine_art_print` et le nom client **Tirage d'art grand format**.

## Une interface a part

Le premier choix important a été de ne pas réutiliser le shell classique de l'éditeur.

Pour ce produit, l'utilisateur ne doit pas avoir l'impression d'être dans un outil de composition. Il doit se sentir dans un assistant atelier : plus calme, plus premium, plus proche d'une table de tirage que d'un canvas multi-outils.

La première interface introduit donc :

- une palette neutre, ivoire, graphite, cuivre discret et sauge ;
- une grande **table de tirage** centrale ;
- une règle millimetree discrète autour du visuel ;
- un cartouche atelier avec format, papier, diagnostic et intervention ;
- un panneau latéral pour le format, le papier, la finition, la quantité et la note client ;
- une vue in situ pour comprendre les proportions ;
- un rail de dossier pour plusieurs tirages dans la même commande.

L'objectif n'est pas de faire une jolie page marketing, mais un outil de confiance : lisible, calme, et assez technique pour rassurer sans faire peur.

## Le regard du tireur

La vraie différence produit est la mise en avant de l'intervention atelier.

Le client peut demander :

- **Faire vérifier mon fichier** ;
- **Confier l'ajustement à l'atelier** ;
- **Etudier un agrandissement propre**.

Le diagnostic qualité évite les mots froids ou punitifs. Les quatre niveaux retenus sont :

- **Très beau rendu attendu** ;
- **Beau rendu grand format** ;
- **Rendu a confirmer ensemble** ;
- **Format a repenser**.

Le message met en avant le contrôle des couleurs, des noirs, du contraste, du rendu papier, et l'expérience de Marc comme tireur depuis plus de 20 ans. L'upscaling est prévu comme une compétence atelier, pas comme une option automatique lancée sans discernement.

## Formats libres, grille indicative

Le tirage d'art ne se limite pas à une liste fermée de formats.

La V1 integre une grille indicative de formats par ratio :

- 3/2 ;
- 4/3 ;
- carré ;
- 16/9 ;
- panoramiques x2, x2.5, x3, x4 ;
- formats courants ;
- DIN.

Mais la grille aide, elle ne bloque pas. Un client peut saisir un format libre comme `26.5 x 40 cm`, tant que l'on reste dans les contraintes papier. La largeur maximale V1 est fixee a **110 cm** ; au-delà, le dossier bascule vers une logique de devis atelier.

L'homothétie reste verrouillée par défaut. L'image n'est jamais deformee : on travaille en `contain` ou en `crop`, avec marges et recadrage explicites.

## Contrat produit et production atelier

Techniquement, une page devient un tirage d'art configure.

Chaque page porte son propre `surface`, ce qui permet un dossier multi-formats : un 40 x 60, un 60 x 80, un 26.5 x 40, avec des papiers et quantités différentes.

Le contrat ajoute `fineArtPrint` dans les pages :

- quantité ;
- papier ;
- mode image ;
- marges ;
- contrecollage ;
- attaches au dos ;
- validation atelier ;
- note client ;
- demande de contrôle qualité ;
- suggestion d'upscaling.

Le backend sait maintenant calculer une estimation de prix indicative, sommer les quantités et exporter le payload projet.

Rectification de cap posée le 16 mai 2026 : le tirage d'art grand format ne doit pas produire un PDF de production KEREDIT. L'atelier doit travailler depuis les fichiers natifs/originaux du client, accompagnes d'un JSON récapitulatif de commande et d'options. Ce JSON sert de bon de travail : formats, papiers, finitions, quantités, marges, notes client, demandes de vérification et indicateurs de validation atelier.

## État pour la suite

Demain, il faut tester visuellement le vrai parcours :

- import JPEG et TIFF ;
- formats `40x60`, `60x80`, `100x150`, `110x110`, `26.5x40` ;
- homothétie, marges et recadrage ;
- diagnostic qualité sur plusieurs resolutions ;
- plusieurs tirages dans le même dossier ;
- refus explicite du PDF de production pour `fine_art_print` ;
- cohérence du paquet atelier : fichiers natifs client + JSON récapitulatif de commande/options ;
- prix indicatif et cas qui exigent une validation atelier.

La base est en place. Il reste maintenant le plus interessant : confronter l'assistant a de vraies images et voir s'il donne au client la sensation juste, celle d'être accompagné plutôt que laisse seul devant des paramètres techniques.
