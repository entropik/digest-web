## Lecture globale

Cette journée quitte un peu le cœur visible de l'éditeur pour renforcer les
outils autour.

Le carnet photo reste present avec la preview de refill, mais le fil principal
devient opérationnel : réduire le bruit, rendre les tests de flux plus faciles,
documenter les prochains chantiers éditeur, et durcir GOF sur les points de
sécurité et de performance.

Ce n'est pas le genre de journée qui donne une grande capture d'écran. C'est le
genre de journée qui évite que la bêta devienne impossible a surveiller.

Le point pratique le plus important est `test-flux`. Une chaîne atelier ne peut
pas dépendre uniquement de tests unitaires ou de clics manuels. Il faut une
commande capable de rejouer le flux WooCommerce -> KEREDIT -> GOF -> atelier de
manière reproductible.

L'autre point utile est la réduction du bruit d'observabilité. Trop de logs
rendent les vrais signaux invisibles. En bêta fermée, on veut voir les erreurs
qui changent une décision, pas tous les battements du système.

## WooCommerce : reprendre sans surcharger

Le chooser de reprise projet WooCommerce est compacté.

Ce n'est pas un détail cosmétique. Dans le flux commerce, l'utilisateur revient
souvent après une interruption : lien de commande, projet déjà cree, photos déjà
présentes, et décision a reprendre. Si la reprise ressemble à un panneau
technique, la confiance baisse.

La correction va dans la même direction que le remplissage carnet :
moins de surface mentale, plus de chemin clair.

## GOF : sécurité, cache et rétention staging

GOF a aussi beaucoup bouge ce jour-la :

- `f1341a8` - durcir l'accès aux artefacts et le rendering ;
- `61e98a6` - borner le cache buffer des assets PDF ;

- `7adff60` - bump GOF **0.1.85** ;
- `e38bf59` / `37b38da` - ajouter puis agrandir le favicon GOF.

Le durcissement GOF compte pour KEREDIT parce que GOF n'est pas une annexe. Il
est la forge d'artefacts : PDF web, PDF print, dossiers atelier, vérification
opérateur. Si GOF garde trop longtemps, expose trop largement, ou consomme trop
en cache, c'est toute la chaîne qui devient fragile.

## Ce que cette journée laisse

Le thème du jour est simple :

```text
moins de bruit -> plus de diagnostic
plus de replay -> moins de superstition
```

KEREDIT commence à avoir les outils nécessaires pour tester un flux atelier
entier sans tout reconstruire mentalement à chaque incident. GOF devient plus
dur sur la sécurité et plus sobre sur les ressources.

Ce n'est pas spectaculaire, mais c'est exactement le genre de travail qui rend
une bêta exploitable.
