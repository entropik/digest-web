Curation is making its way into Firefox

The curation extension becomes a Chrome and Firefox extension based on the same code. The Firefox 1.5.0 version is validated, signed and then officially installed via AMO without extending the service’s trust to all the browser’s extensions. The feature on the ‘software factory’ becomes the first post published in the `FOCUS` format, alongside the two previous features on agent farms and ADEs, with a visual identity combining NASA technical archives, a grid layout and large typography.

Requests and discussions

  • Install the extension in Firefox and make it an official target.
  • Carry out validation and submission directly from Firefox.
  • Maintain a clear, documented and verifiable workflow prior to publication.
  • Prepare a well-documented post on the trend towards software factories based on seven recent videos, whilst retaining the videos in the source selection.

Decisions

  • Firefox 142 becomes the minimum version required to have native consent for data categories on desktop and Android.
  • The stable Gecko identifier is curation@digest.ooblik.com.
  • The manifest declares browsing history and site content, as the URL, title, description and any selection are transmitted.
  • The service only accepts exact moz-extension UUIDs configured per profile. No Firefox wildcards are permitted.
  • The AMO release remains unlisted, as does the Chrome Web Store release.
  • The standard shortcut is Ctrl+Maj+Y (Cmd+Maj+Y on macOS): real-world testing has shown that Ctrl+Maj+D is reserved for Firefox bookmarks.
  • The manifest command remains format-specific: _execute_action in Chrome MV3 and _execute_browser_action in Firefox MV2.
  • This post builds on previous instalments dedicated to agent farms and ADEs by examining the complete workflow: code, tests, review and pull request.
  • The three thematic dossiers dated 28 August, 29 August and 2 September are labelled editorial_type: "focus". Their public titles are prefixed with FOCUS -. The dated Digests retain their historical layout.
  • The 2 September Focus is published: its seven videos are once again visible in the catalogue and are still listed as sources at the end of the post.

Implementation

  • Added Firefox builds, ZIP files and development commands to WXT.
  • Added the Gecko manifest, data declarations and source package.
  • Extended CORS and Better Auth configuration to explicitly authorised Firefox origins. Added a Firefox artefact to the extension’s publication workflow.
  • Added a Firefox artefact to the extension’s release workflow.
  • Updated the architecture, design decisions, privacy policies and procedures for Chrome and Firefox.
  • Initial upgrade of the extension to version 1.5.0 and the website to version 1.25.0.
  • Fixed the registration diagnostic: a rejected Firefox origin is no longer presented as an expired session. The fix brings the extension to version 1.5.1 and the website to version 1.25.1.
  • The first test following authorisation revealed a second issue specific to Firefox: the modern API scripting.executeScript may refuse the injection even though the pop-up does indeed have activeTab. Extension 1.5.2 retries the same local function using the Manifest V2 API tabs.executeScript, without extending the permissions, and now distinguishes this refusal from a connection issue.
  • Drafting of the blog post ‘Software Factory: code is no longer the bottleneck’ following analysis of the videos and cross-referencing with feedback, research into agent-based modelling, DORA, METR and containment practices.
  • Added a ranking of fifteen open-source projects by popularity and maturity, distinguishing between complete factories, control plans, agents, sandboxes, cockpits and review tools.
  • Added the seven canonical videos to the catalogue, without their tracking parameters, along with titles, summaries and tags.
  • Added the ‘Focus’ format to the publishing template, creation and editing forms, archive cards, blog posts and LinkedIn shares.
  • Focus cards use a dedicated technical photograph, a yellow and black colour scheme and a prefixed title, without replicating the red Digest banner.
  • Creation of a deterministic Focus generator in the 1200 × 627 and 1200 × 1200 formats. Four NASA images already documented in the project are prepared in black-and-white JPEG format, then recomposed in duotone with a grid and a bold title over a single full-frame photograph. The six posters for the three Focus features are regenerated.
  • The new editorial and visual format brings the site to version 1.26.0.
  • The grid for the fifteen projects is reduced to four columns and widened to 1120 px. The description takes up almost half the space, whilst the stars and the licence remain grouped together. This correction brings the site to version 1.26.1.
  • The static deployment forces the use of Git v1 to resolve the SHA, then directly downloads its immutable archive: no persistent Git clone now depends on the server’s faulty transmission. A new fingerprinted CSS asset prevents the cached copy with altered alt text from being used. The site is updated to version 1.26.2.

Validation and deployment

  • The extension’s 110 tests, type checking and the Chrome and Firefox builds all pass.
  • web-ext lint validates the Firefox manifest without any errors, warnings or notes.
  • The 239 tests for the administration service and its build pass.
  • The package has been temporarily installed and tested in Firefox 155: the shortcut opens the form and correctly pre-fills the URL and title.
  • The temporary UUID of the tested profile is b63b2a6a-61de-4f10-9d93-bb8e2494142f.
  • The Firefox 1.5.0 package and its reproducible source archive passed AMO validation without any errors or warnings.
  • The unlisted version was submitted under the developer name OOBLIK. Mozilla automatically approved it on 2 September 2026, under reference Addon#3064842, with the comment ‘automatic validation’.
  • The XPI signed by 824fca3040734408979d-1.5.0.xpi, AMO file 5000165, was installed from Firefox. The add-on manager confirms that OOBLIK Digest — Curation 1.5.0 is enabled.
  • A check on https://example.com/ confirms that the URL and title are pre-filled, the link is validated and the save button is enabled. No test draughts have been saved.
  • The first actual save confirmed that the owner’s session was valid, but that the origin of the signed Firefox profile was not yet on the service’s whitelist. The CORS check returned INVALID_ORIGIN for moz-extension://b63b2a6a-61de-4f10-9d93-bb8e2494142f.
  • The editorial import accepts seven links, with no duplicates or private destinations.
  • The actual rendering is checked in the browser at 1440 px and 390 px: prefixes, maps, images, seven links and aspect ratios are correct, with no horizontal overflow.
