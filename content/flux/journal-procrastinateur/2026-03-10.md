## Complications et décisions

Docker a été le premier mur. La résolution de `@krampouz/shared` dans un conteneur est un classique pnpm monorepo : le workspace protocol ne fonctionne pas comme en local. Il a fallu externaliser les secrets hardcodes aussi.

La centralisation tenant était nécessaire : le code de résolution était eparpille dans plusieurs fichiers.

## Opinions et reflexions

2060 lignes pour l'admin produits/templates en un commit, c'est le genre de chose que Claude Code rend possible mais qui demande une relecture attentive. Le workflow postcard v1 est un jalon important : c'est la première fois qu'un produit concret traverse tout le stack.

## Mini-lexique

- `Docker` — technologie de conteneurs pour lancer l'application dans un environnement reproductible.
- `tenant` — espace logique d'un client ou d'une organisation dans une architecture multi-tenant.
- `CRUD` — create, read, update, delete : les quatre opérations de base sur des données.
- `monorepo` — dépôt unique contenant plusieurs applications ou packages.
